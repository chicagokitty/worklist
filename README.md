# worklist

一个把任务、截止日期和阅读材料放在一起的个人工作台。当前为 **布局演示版**，所有内容均为虚构示例。

[打开网页](https://chicagokitty.github.io/worklist/)

## 页面结构

- **今天**：当天重点、任务清单、近期截止日期、快捷入口。
- **全部任务**：课程／项目筛选、搜索、任务详情。
- **资料库**：文章、讲义、笔记与任务相互关联。
- **已完成**：完成记录归档。

点击任务打开详情；点击材料打开示例阅读页；勾选任务可预览完成后的样式。勾选只影响当前页面，刷新即恢复。

## 当前阶段

先确定排版、布局和交互，再迭代视觉与栏目。真实任务与阅读文件尚未接入。本演示站公开可见，接入个人内容前需另行确定访问权限与存放方案。

## 文件

- `index.html`：页面结构
- `style.css`：桌面和手机样式
- `demo-data.js`：纯虚构演示内容
- `app.js`：筛选、搜索、详情和演示完成状态
- `materials/sample-reading.html`：原创材料占位页

无需安装依赖或构建。GitHub Pages 从 `main` 分支根目录发布。
